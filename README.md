# Behavioral Design Patterns in PHP

Laboratory Activity #4: Applying Behavioral Design Patterns Using PHP (plain PHP).

| No. | Pattern | Application | Folder |
|-----|---------|-------------|--------|
| 1 | Chain of Responsibility | Student Request Processing System | `01-chain-of-responsibility` |
| 2 | Command | Student Action/Command System | `02-command` |
| 3 | Interpreter | Student Search/Query System | `03-interpreter` |
| 4 | Iterator | Student Record Collection | `04-iterator` |
| 5 | Mediator | Student Communication System | `05-mediator` |
| 6 | Memento | Student Profile Undo System | `06-memento` |
| 7 | Observer | Grade Notification System | `07-observer` |
| 8 | State | Student Enrollment Status | `08-state` |
| 9 | Strategy | Grade Calculation System | `09-strategy` |
| 10 | Template Method | Student Report Generation | `10-template-method` |
| 11 | Visitor | Student Record Operations | `11-visitor` |

## How to run

Requires PHP 7.4 or newer. Open a terminal inside a pattern folder and run:

```
php index.php
```

Each folder contains the PHP source files, an `index.php` demonstration, and the classes/interfaces for that pattern.
